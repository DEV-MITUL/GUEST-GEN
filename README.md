## 💻 Installation & Usage

Copy and paste the following commands into your terminal (**Termux** or **Linux**) to install and run the tool:

### 1. Clone the Repository
```bash
git clone https://github.com/DEV-MITUL/GUEST-GEN.git
```

### 2. Navigate to Directory & Set Permissions
```bash
cd GUEST-GEN && chmod +x BMGEN
```

### 3. Run the Tool
```bash
./BMGEN
```

### ⚡ Quick One-Line Command (Copy & Paste)
```bash
git clone https://github.com/DEV-MITUL/GUEST-GEN.git && cd GUEST-GEN && chmod +x BMGEN && ./BMGEN
```
